# 牌画像について

このフォルダの画像は、FluffyStuff 氏の riichi-mahjong-tiles をもとに作りました。

- 元データ: https://github.com/FluffyStuff/riichi-mahjong-tiles （確認したコミット: 26e127b、2024-06-15）
- ライセンス: パブリックドメイン（CC0 1.0） https://creativecommons.org/publicdomain/zero/1.0/
- 加工内容: 牌の地と絵柄を 1 枚に重ね、180×240 ピクセルに縮小し、色数を減らしました。裏面（back.png）は色を赤から青緑に変えました（`tools/build_tiles.py`）
